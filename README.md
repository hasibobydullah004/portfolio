# Creative Hub — Next.js Portfolio Website

A boutique editorial portfolio and digital studio website built with **Next.js 15 (App Router)** and **React 19**, retaining the refined earthy aesthetic and incorporating the interactive architectural stats section with hover inversion.

## ✨ Features

- **Architectural Stats Section ("Twelve years, in numbers.")**:
  - Technical top ticker / ruler bar (`A1 PROJECTS`, `B1 TIME`, `C1 REACH`, `D1 LOYALTY`) with tick marks.
  - Interactive **white-inversion hover effect** matching the reference video: hovering any column smoothly turns its background solid white, with dark high-contrast typography and subtle elevation.
  - Preserves subtle earthy color indicators (Sage, Mauve, Ochre, Coral).
- **Hero Desk Flat-Lay**: Stylized desk composition with accessories and warm glowing amber laptop display.
- **Six Crafts, One Studio**: Interactive horizontal accordion showcasing Web Design, Development, E-commerce, Branding, Motion, and Support.
- **Selected Work**: Curated gallery of 8 design projects with smooth hover reveals and metadata.
- **Twelve Weeks, No Surprise**: Visual 12-week roadmap and milestone tracker.
- **Promises, in Writing**: Asymmetric commitment cards with circular graphic motifs and quality audit metrics.
- **Your Budget, Our Best**: Interactive budget slider ($5k–$45k) dynamically updating project scope, deliverables, and team allocations.
- **In Their Words**: Client reviews with 4.9 rating and multi-colored testimonial cards.
- **Next Start Selector**: Interactive month-by-month availability picker.
- **Editorial Footer**: Newsletter "Let's chat" form, structured directory, and contact CTA.

## 🚀 Running the Project

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
